# Technical Architecture

This directory will contain the approved technical design. The PRD defines product requirements; these documents define implementation decisions.

Planned documents:

- `system-architecture.md` — components, boundaries, deployment and data flows.
- `database-design.md` — entities, relationships, migrations, indexes and retention.
- `api-specification.md` — API routes, contracts, validation and errors.
- `ai-engine.md` — provider abstraction, prompts, tool execution, context and memory.
- `integrations.md` — Apple Calendar, Google Calendar, Spotify, Maps, Waze, Shortcuts and Gmail.
- `security.md` — authentication, authorization, secrets, privacy and threat model.

No detailed architecture has been approved yet. Open questions are tracked in `../01-product/PRD-v1.0.md` section 15.
